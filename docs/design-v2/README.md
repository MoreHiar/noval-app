# Noval 2.0 设计讨论稿

V1 的代码、设计和资源保留在 `version-1.0.0` Git 标签；V1 设计稿仍在 `docs/desgin/`。本目录只用于讨论 2.0，不修改 Expo 应用。

- [交互原型](index.html)：直接在浏览器打开，左侧切换页面，右侧切换状态。
- [12 幅画板总览](overview.html)：同时查看主要页面和关键状态。
- [PNG 预览](previews/)：便于离线评审。

参考画板为 390 × 844 逻辑尺寸。原型中的小说与漫画推荐、收藏和漫画分镜均为版式示意，不代表当前书源已经支持发现规则或漫画阅读。

## 已确认的交互

1. 底部导航为书架、小说、漫画、我的。搜索作为书架、小说、漫画顶部入口；书源管理从我的进入。
2. 书架进入搜索默认「全部」，小说和漫画进入时默认各自类型。每次从顶部入口新进入搜索时清空输入；从详情返回搜索时保留关键词、结果、滚动位置。
3. 搜索栏固定，历史和结果独立滚动。历史只记录非空的实际搜索，按最近使用排序，重复词去重；设计建议最多保留 20 条，支持单条删除和全部清空。具体保存策略仍待实现时验证。
4. 书架使用「全部／小说／漫画」筛选，同时在每项显示类型标签。保留立体和列表视图；混合内容默认列表更利于识别类型，任何筛选下都可切换立体视图。
5. 小说和漫画各自选取该类型第一个已启用且发现规则可运行的书源。没有可用规则时展示空状态和书源管理入口；不推断任意网站首页的结构。
6. 漫画阅读按纵向连续图片设计，图片懒加载、章节切换和进度恢复的正式实现需在找到真实漫画源后验证。

## 页面和状态

| 页面 | 主要状态 | 设计目的 |
| --- | --- | --- |
| 书架 | 全部、小说、漫画、空筛选 | 内容类型可识别，筛选和视图模式不互相干扰 |
| 小说 | 无推荐规则、有推荐 | 显示当前推荐源，不伪造首页内容 |
| 漫画 | 无漫画源、有推荐 | 新用户能够进入书源管理；有源后显示图像优先的推荐列表 |
| 搜索 | 历史、结果、无结果 | 固定输入栏；来源范围和搜索状态清晰 |
| 我的 | 阅读统计、书源入口 | 书源管理成为固定的设置行 |
| 漫画详情 | 简介、目录、收藏 | 与小说详情保持一致的信息结构 |
| 漫画阅读 | 连续图片、章节工具 | 阅读内容全宽，工具让位于画面 |

## 尚需真实书源验证

- Legado 图片源的 `bookSourceType = 2` 只是配置类型，现有适配器尚无发现接口，也未实现漫画图片页解析。不能仅凭 `enabledExplore` 声称书源可用。
- 推荐页需要检查 `exploreUrl`、`ruleExplore` 与解析器的支持范围；首个源失败时显示错误和切换书源入口，不静默换源。
- 漫画阅读进度建议记录章节与图片序号／滚动位置，具体字段和恢复策略需用实际内容验证。

## 验证

预览由 `node docs/design-v2/render-previews.cjs` 导出。原型应在 320、390、430、768、1440 宽度下检查溢出、点击和固定搜索栏行为；应用开发开始后再根据 Expo SDK 58 文档落实原生导航、列表和存储。
